# סוכנות גיבורי ה־AI

משחק לימודי מלא בעברית ללימוד חשיבה ביקורתית, בניית פרומפטים, איטרציה, אימות ופרטיות. המימוש הוא SPA מקומי ב־React, TypeScript ו־Vite, ללא אימות משתמשים, מסד נתונים או תלות ב־Base44 בזמן הריצה.

## הפעלה

דרישות: Node.js 20 ומעלה ו־npm.

```bash
npm ci
npm run dev
```

האפליקציה תיפתח ב־`http://localhost:5173`.

פקודות אימות:

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

`npm run preview` מגיש את תיקיית `dist/` לאחר build לצורך smoke test מקומי של גרסת הייצור.

אם משתנים קובצי המקור שבתיקיית `handoff/assets/characters`, יש להריץ:

```bash
npm run assets:optimize
```

אם משתנים קובצי המקור שבתיקיית `incoming/audio`, יש להריץ (דורש רשת בפעם הראשונה להתקנת `ffmpeg-static`):

```bash
npm run audio:optimize
```

## מה כלול

- מסע מלא של 23 קרבות בארבעה אזורים ומשימת גמר.
- שבע תבניות אינטראקציה מונעות־נתונים, עם הערכה דטרמיניסטית.
- סולם משוב בן שישה ניסיונות, שמירת רכיבים נכונים והשלמה מודרכת.
- ניקוד של 1–5 כוכבים בחצאי כוכב; שידור חוזר מעניק רק את הפרש השיא החיובי.
- ארבעה ביקורי סדנה, שלושה פריטים בכל ביקור, רכישה והרכבה מקומיות.
- שלושה שלבי בונוס אופציונליים; הקטגוריה נבחרת אקראית והפרס קבוע וגלוי: 2 כוכבים.
- קרב 23 עם כתיבה חופשית עד 600 תווים, שער בטיחות מקומי, מסווג דטרמיניסטי ומפתחות תוצאה סגורים.
- התקדמות, הגדרות ועסקאות אידמפוטנטיות ב־LocalStorage תחת `ai_heroes_progress_v1`.
- RTL מלא, יעדי מגע של 44px לפחות, ניווט מקלדת, focus בולט, טקסט חלופי והפחתת תנועה.
- מוזיקה (7 רצועות, לפי אזור/מסך) ואפקטים (4 stingers מתוך 42 נכסי שמע גולמיים) דרך Howler.js, עם מתגים נפרדים למוזיקה ולאפקטים; פעולות UI קצרות (בחירה, שיגור, מגן, הרכבה, אזור) נשארות טונים מסונתזים מקומית ב־Web Audio — ראו `docs/AUDIO_TECH_DECISION.md`. רישוי קובצי השמע טרם אושר ידנית — ראו `docs/THIRD_PARTY_ASSETS.md`.
- 42 איורי דמויות שסופקו, לאחר המרה מ־94.3MB PNG לכ־1.8MB WebP.

## ארכיטקטורה

```text
src/
  content/      נתוני 23 הקרבות, האזורים, הבונוסים והחנות
  engine/       הערכה וניקוד טהורים ודטרמיניסטיים
  services/     שמירה מקומית, שמע וממשק מסווג קרב הגמר
  state/        GameProvider וממשק הפעולות של האפליקציה
  features/     מסכים וזרימות משחק
  components/   רכיבי UI משותפים
  schemas/      טיפוסים וסכמת מצב
  tests/        בדיקות תוכן, ניקוד, התמדה ובטיחות
```

קובצי ה־handoff המקוריים (כולל 42 ה־PNG הגולמיים) נשמרים ללא שינוי בתיקיית `handoff/` ואינם נכנסים להיסטוריית Git, כדי לא לשכפל כ־94MB. עותק מסודר של מסמכי העיצוב/UX/נגישות (ללא הנכסים הכבדים) נמצא ב־`docs/handoff/` ונכנס ל־Git. גרסאות ה־WebP המוכנות לייצור נמצאות תחת `public/assets/characters/`. באותו אופן, קובצי המוזיקה/SFX הגולמיים (26MB) נמצאים ב־`incoming/audio/` ונכנסים ל־Git כמקור אמת לצנרת האופטימיזציה; הגרסאות המכווצות שבפועל נטענות בזמן ריצה נמצאות תחת `public/audio/`.

## פרטיות ובטיחות בקרב 23

הטקסט החופשי נשמר רק ב־state הזמני של המסך. הוא אינו נכתב ל־LocalStorage, אינו נרשם ללוג ואינו נשלח לרשת. לפני סיווג מתבצעים נרמול, חסימת דפוסי מידע אישי, חסימת תווים לא מורשים ורשימת־היתר מצומצמת למילות המשימה. המסווג הנוכחי מקומי לחלוטין ומחזיר רק אחד ממפתחות התוצאה הסגורים.

מסמכי ה־handoff כללו סתירה: מסמך Review סימן את בטיחות קרב 23 כחסם, בעוד שמסמך הקרב תיאר אותה כמאושרת. המימוש בוחר בנתיב המחמיר: אין קריאת AI ואין העברת טקסט חופשי החוצה. ספרות ASCII אינן מתקבלות בשער המקומי; המשתמש מתבקש לכתוב מספרים במילים.

## חיבור עתידי ל־Base44

אין בפרויקט קוד Base44 ואין צורך בחיבור כדי להריץ אותו. כאשר תיווצר אפליקציית Base44:

1. שמרו על ה־frontend הזה כאפליקציה נפרדת.
2. הגדירו ב־Base44 פונקציית backend בלבד שמקבלת טקסט שכבר עבר את שער הבטיחות המקומי.
3. החזירו מהפונקציה רק מפתח מתוך `Battle23OutcomeKey`.
4. הוסיפו adapter חדש שמממש את `FinalBattleClassifier` ומאמת את הפלט באמצעות `validateClassifierOutcome`.
5. אל תשמרו ואל תרשמו את הפרומפט החופשי בפונקציה, במסד נתונים או בלוגים.
6. החליפו את `LocalFinalBattleClassifier` ב־adapter החדש באמצעות משתנה סביבה לכתובת backend; אל תחשפו מפתחות סודיים ב־Vite.

כך Base44 נשאר שכבת backend בלבד, כפי שנדרש, והמשחק ממשיך לעבוד מקומית גם במקרה של כשל רשת.

## QA ומגבלות נכסים

הבדיקות האוטומטיות מאמתות את שלמות 23 הקרבות, שבע התבניות, אבני הדרך, הניקוד, השידורים החוזרים, העסקאות החד־פעמיות, המיגרציה ושער הבטיחות. `npm run build` מפיק build ייצור תקין.

קובצי המקור שסופקו כוללים רק איורי דמויות. בחלקם רקע דמוי־שקיפות כבר אפוי בתוך התמונה, ושלושת קובצי המפה/התעודה שסופקו כוללים טקסט אפוי שאינו מתאים למוצר. לכן המפה, התעודה, הרקעים, האייקונים והחנות בנויים ב־HTML/CSS נגישים, והאיורים משמשים כפאנלים קומיקסיים חתוכים. בסביבה שבה פותח הפרויקט לא היה דפדפן אוטומציה זמין; מומלץ לבצע smoke test ידני קצר ברוחבים 360, 430, 768 ו־1280 פיקסלים.
